## Customer commerce response notes

All customer API responses use `{ success: true, data }`; errors use the
central `{ success: false, error: { code, message, details } }` shape.

- `GET /api/cart` returns `data.items`, `data.totals`, and
  `data.hasBlockingIssues`. Lines are re-priced from current products and
  include option labels and issue details. Artwork metadata is included only
  for a file owned by the current account or guest session. Image previews
  reference the access-controlled `/api/artwork/:id/preview` route; private
  files are never served from a public URL.
- `GET /api/checkout/preview` returns line items, `subtotalMinor`,
  `discountMinor`, `shippingMinor`, `taxMinor`, `totalMinor`, `currency`,
  `issues`, `hasBlockingIssues`, `shippingConfigured`, and `taxConfigured`.
- `POST /api/orders` requires a UUID `Idempotency-Key` header. Its strict JSON
  body is `{ contact: { name, email, phone? }, shippingAddress: { line1,
  line2?, city, state, postalCode, country }, billingAddress?, 
  billingSameAsShipping, customerNote? }`. Address `phone` is not accepted;
  phone is optional on `contact`. If `billingSameAsShipping` is false,
  `billingAddress` is required. The server recalculates pricing and stock.
  Success is HTTP 201 with `data.order`.
- `POST /api/orders/:orderNumber/pay` accepts optional `{ email }` for guests
  and returns `{ checkoutUrl, expiresAt }` in `data`.
  `POST /api/orders/:orderNumber/payment/confirm` accepts the same optional
  guest body and returns `{ status }`. The payment-status GET accepts guest
  `email` as a query parameter and returns `{ status, orderStatus }`.
- `GET /api/orders` returns `{ items, pagination }` in `data`.
  `GET /api/orders/:orderNumber`, `POST /api/orders/lookup`,
  `POST /api/orders/:orderNumber/cancel`, and the replacement-artwork POST
  return `{ order }` in `data`. Guest lookup requires `{ orderNumber, email }`
  and intentionally uses the generic `ORDER_LOOKUP_FAILED` error.
- Public settings expose `supportedCountries` as a configured string array;
  an empty array means the client must collect country as a text field.
